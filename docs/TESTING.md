# Manual testing checklist

- [ ] Start the C++ server and open `http://localhost:8080`.
- [ ] Add an expense with title, category, amount and date.
- [ ] Check that the expense appears in the table and totals update.
- [ ] Add an income entry and check that balance updates.
- [ ] Change the monthly budget and check the remaining amount.
- [ ] Stop and restart the server; verify that saved entries remain.
- [ ] Try submitting with an empty title or invalid amount.
